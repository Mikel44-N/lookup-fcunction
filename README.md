# Formulas and Functions Projects
This repository showcases a collection of Excel projects demonstrating logical operators, conditional formulas, text manipulation, array formulas, date & time functions, data validation, SUMIF/SUMIFS/COUNTIFS, and conditional formatting. Each project includes a clean, structured dataset and highlights practical applications for data analysis, reporting, and automation.

1. Logical Operators & Conditional Analysis
Description:
Analyzed student scores using IF, AND, and OR functions to classify results and identify achievers.
Tasks Completed:
•	Returned “PASS”/“FAIL” based on scores.
•	Assigned letter grades (A–F) using score ranges.
•	Identified outliers (<60 or >90).
•	Highlighted top achievers based on gender and score >95.
Outcome: Clean, structured dataset demonstrating conditional logic and multi-condition formulas.
Skills: IF statements, AND/OR, logical operators, data analysis, Excel formulas.

2. Sales Analysis Using SUMIF, SUMIFS & COUNTIFS
Description:
Performed conditional aggregation and counting to summarize sales data by category, store, and product type.
Tasks Completed:
•	SUMIF to calculate total sales by category.
•	SUMIFS to sum sales and revenue by store and product type.
•	COUNTIFS to count product IDs by store and type.
Outcome: Clean dataset showcasing conditional aggregation techniques.
Skills: SUMIF, SUMIFS, COUNTIFS, data validation, Excel analysis.

3. Dynamic Lookup with INDEX & MATCH

Tasks Completed:

4. Dynamic Ranges with OFFSET, COUNTA & SUM
Description:
Applied dynamic ranges for calculations that adjust automatically as data grows.
Tasks Completed:
